Describe what you need in plain language and watch it become a working tool, then learn to steer, check and fix what the AI builds.

You do not need to be a programmer to build useful software any more. Vibe coding means describing what you want in plain language and letting an AI assistant write the code. This course shows you how to do it well: how to ask, how to check the result and what to do when it breaks.
